# Just MCP it Bro

Welcome to **Just MCP it Bro**! Because having a million different repositories for your Model Context Protocol integrations is *so* last year. We shoved them all in here. You're welcome.

## What's in the box?

This monstrosity of a monorepo holds the following integrations:

| Integration | What it does | Where to find it |
|-------------|-------------|-----------|
| **Jira MCP** | Pokes Jira with a stick so your AI can manage issues without crying. | [`/Jira MCP`](./Jira%20MCP) |
| **Salesforce MCP** | Performs dark magic to connect with Salesforce records. | [`/Salesforce MCP`](./Salesforce%20MCP) |
| **xMatters MCP** | Wakes people up when servers inevitably catch fire. | [`/Xmatters MCP`](./Xmatters%20MCP) |

## Getting Started (Read the manual)

- [Salesforce MCP Instructions](./Salesforce%20MCP/README.md)

## Why a Monorepo?

Because I got tired of switching tabs. Also, it:
- Makes updating things less painful.
- Let's us share config files like a big happy family.
- Looks vaguely more professional.
