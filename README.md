# 🚀 Just MCP it Bro

Welcome to **Just MCP it Bro**! This repository is a centralized hub for multiple Model Context Protocol (MCP) integrations, designed to supercharge your AI agents with seamless access to enterprise tools.

## 📦 Included MCPs

This monorepo contains the following MCP integrations, each organized in its own directory:

| Integration | Description | Directory |
|-------------|-------------|-----------|
| 🔹 **Jira MCP** | Interact with Jira issues, projects, and boards. | [`/Jira MCP`](./Jira%20MCP) |
| 🔹 **Salesforce MCP** | Connect with Salesforce records, queries, and data. | [`/Salesforce MCP`](./Salesforce%20MCP) |
| 🔹 **xMatters MCP** | Manage incidents, alerts, and on-call schedules. | [`/Xmatters MCP`](./Xmatters%20MCP) |

## 📖 Getting Started

Each MCP integration has its own setup instructions, configuration requirements, and capabilities. Navigate to the respective subfolder and read its `README.md` for detailed information on how to install and use it.

- [Jira MCP Documentation](./Jira%20MCP/README.md)
- [Salesforce MCP Documentation](./Salesforce%20MCP/README.md)
- [xMatters MCP Documentation](./Xmatters%20MCP/README.md)

## 🛠️ Why a Monorepo?

Managing multiple MCPs in a single repository makes it easier to:
- **Centralize updates and maintenance** across multiple integrations.
- **Share common utilities** and configurations.
- **Provide a unified experience** for users looking to extend their AI models with multiple enterprise tools.
